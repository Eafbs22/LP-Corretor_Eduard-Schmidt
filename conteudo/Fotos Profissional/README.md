Fotos Profissional — fotos originais do usuário

Propósito
- Armazenar fotos originais do usuário que serão usadas para geração de designs e posts.

Como adicionar fotos
- Copie/arraste suas imagens para esta pasta a partir do seu computador.
- Mantenha o nome original ou use um formato claro: `YYYY-MM-DD_foto-perfil.jpg` ou `foto-perfil.jpg`.

Privacidade e licença
- Coloque aqui apenas imagens que você tem o direito de usar.
- Se estas imagens contiverem informações sensíveis, evite comitar para repositórios públicos.

Uso com o kit
- As ferramentas de geração de design procurarão nesta pasta por imagens originais.
- Recomenda-se manter apenas arquivos finais nesta pasta; versões editadas podem ficar em `conteudo/` ou `marca/`.

Git (opcional)
- Para adicionar ao Git:

  git add "conteudo/Fotos Profissional/*"
  git commit -m "Adiciona fotos originais do usuário"
  git push

- Se você prefere não versionar imagens, adicione a pasta ao `.gitignore`.

Consentimento
- Ao colocar imagens aqui você confirma que autoriza o uso destas imagens para criação de conteúdo e designs dentro deste projeto.

Contato
- Se quiser que eu mova a imagem para cá e faça commit, informe o nome do arquivo e permita o commit automático.
